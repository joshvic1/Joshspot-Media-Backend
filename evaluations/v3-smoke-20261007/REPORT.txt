16. REMAINING RISKS AND STOP
This run demonstrates that retrieval is fixed at the execution level, not that
overall conversations are repaired. The response protocol currently makes
correct answers fragile, the model still guesses keys, selection persistence
is inconsistent, and generic plan validation can block a human escalation.
The shared repair counter means a recoverable planning error can remove the
only opportunity to repair final composition. Citation/coverage validation is
not semantic entailment checking. Repeated nested commercial data increased
context size substantially even for short conversations.

No conclusions about course switching, payment, cap correction, deferral or
long-term continuity are justified: those turns were not reached. No changes
or new evaluation are proposed/executed as part of this task. Owner review next.
